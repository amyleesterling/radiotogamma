# Radio to Gamma

**One phenomenon. Sixteen orders of magnitude.**

An interactive electromagnetic-spectrum observatory: choose two signals and
compare their frequency, wavelength, period, and photon energy — with a
focus-lens spectrum ruler, a real-object wavelength scale, an interactive
lockstep explorer, the equal-power photon revelation, and the octave ladder
from one footstep to the Oort cloud.

Live at **[radiotogamma.net](https://radiotogamma.net)**.

Born as part of [hbdanny.com](https://hbdanny.com) — patent-themed games for
Danny Hillis — and grown into its own site. The `vendor/scifi-ui` styles are
copied unmodified from
[amyleesterling/scifi-ui](https://github.com/amyleesterling/scifi-ui).

Static site, no build step: open `index.html`, or append `?test=1` to run the
conversion self-tests.
